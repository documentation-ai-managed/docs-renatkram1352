## Document Organization and Folders

Organize your documentation using hierarchical folders and smart tagging. Create nested structures to mirror your project's architecture, making it simple to locate files.

<Steps>
  <Step title="Create Folders" icon="folder-plus">
    Navigate to your workspace and select <kbd>New Folder</kbd>. Name it descriptively, such as `api-reference`.
  </Step>
  <Step title="Move Documents" icon="move">
    Drag and drop MDX files into folders. Use tags like `v1.0` for quick filtering.
  </Step>
  <Step title="Manage Permissions" icon="shield">
    Set folder-level access to control who can view or edit content.
  </Step>
</Steps>

<Callout kind="tip">
  Use consistent naming conventions, like `feature-{name}` for feature docs, to enhance discoverability.
</Callout>

## Version Control for Docs

renatkram1352 integrates version control directly into your docs space. Track changes, revert to previous versions, and branch docs for experiments—all without leaving the platform.

```bash
# Commit changes to a doc
git add docs/features.mdx
git commit -m "Add collaboration section"
git push origin main
```

<CodeGroup tabs="CLI,API">
  ```bash
  # Pull latest versions
  git pull origin main
  ```
  ```javascript
  // Fetch doc versions via API
  const response = await fetch('https://api.example.com/docs/features.mdx/versions', {
    headers: { Authorization: `Bearer ${YOUR_API_KEY}` }
  });
  const versions = await response.json();
  ```
</CodeGroup>

## Search and Export Functionalities

Search across all docs with full-text indexing. Export to PDF, HTML, or Markdown in bulk.

| Feature | Description | Formats Supported |
|---------|-------------|-------------------|
| Global Search | Fuzzy matching on titles and content | Instant results `<100ms` |
| Advanced Filters | By folder, tag, or date | PDF, HTML, MD, ZIP |
| Bulk Export | Select multiple docs | Custom branding |

<Callout kind="success">
  Exports include version snapshots, ensuring you share stable content.
</Callout>

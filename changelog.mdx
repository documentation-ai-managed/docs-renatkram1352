## New Features

- Added real-time collaboration for shared documentation spaces
- Introduced custom branding options with your brand color (`#3B82F6`)

## Improvements

- Enhanced search functionality with fuzzy matching
- Faster page rendering by 40% for large docs sites
- Better mobile responsiveness across all components

## Bug Fixes

- Fixed parsing errors in nested code blocks
- Resolved issues with special character escaping in prose
- Corrected frontmatter validation for blank lines

</Update>

<Update label="2024-08-10" description="v1.0.0" tags={["breaking", "feature"]}>

## Breaking Changes

- Removed legacy `<Mermaid>` component; use code blocks only
- Updated attribute syntax to require double quotes for strings

## New Features

- Core MDX documentation engine with 15+ components
- YAML frontmatter validation and auto-parsing
- Full support for Lucide icons in all components

## Initial Setup

- Basic project scaffolding for new docs sites
- Default themes with customizable brand colors

</Update>

## Upgrade to the Latest Version

Follow these steps to upgrade renatkram1352 and benefit from the newest features.

<Steps>
  <Step title="Check Current Version" icon="package">

    Run the version check command:

````bash
npm list renatkram1352
````

  </Step>
  <Step title="Update Package" icon="upload">
    <Tabs>
      <Tab title="npm" icon="npm">
````bash
npm install renatkram1352@latest
````
      </Tab>
      <Tab title="yarn" icon="yarn">
````bash
yarn add renatkram1352@latest
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Verify Changes" icon="check-circle">

    Test your docs site:

````bash
npm run dev
````

    Review the changelog above for migration notes.

  </Step>
</Steps>
